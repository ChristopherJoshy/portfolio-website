# Christopher Joshy — Portfolio

A five-page HTML5 portfolio built with one external stylesheet.

## Pages

- Home — introduction and featured project
- About — focus, recent work, and skills
- Gallery — photo collection
- Contact — public contact link
- Sign up — registration form with 15 fields

Open `index.html` in a browser to view the site. The form is a front-end assignment demo and does not store submissions. Gallery photos load from Unsplash.

## GitHub Pages

Publish the repository from the `main` branch and the root folder in **Settings → Pages**.
